# 規約・著作権の管理方針

## 公開禁止 (点数に関係なく。ytops/qa.py が自動判定)
- 著作権侵害のおそれ (他人の動画・映画・テレビ・SNS・浮世絵などの画像の転載。**素材は自作のみ**)
- 重大な事実誤り (LLM の裏取りで high の誤り)
- 過去動画との台本の一致 60% 以上 (再利用・独自性のないコンテンツ)
- スパム・エンゲージメントの不正誘導 (相互登録・「高評価しないと…」など)
- タイトルなし・100 文字超、映像/音声ストリームなし

## 人間の確認に回すもの
- 医療・法律・金融の助言を含むもの
- 実在の人物・団体の評価に関わるもの
- 重要な主張を裏取りできなかったもの
- LLM による事実確認が実行できなかったもの

## 素材の管理
| 素材 | ライセンス | 記録 |
|---|---|---|
| AI 画像 (Pollinations / FLUX) | 生成物。実在の人物・ロゴ・作品は指示しない | 動画ごとの plan.json に画像プロンプト、概要欄に「画像: AI生成 (Pollinations.ai / モデル名)」 |
| イラスト (Noto Emoji) | Apache 2.0 | 概要欄にクレジット |
| フォント (M PLUS Rounded 1c / Dela Gothic One / Shippori Mincho) | SIL OFL | 概要欄にクレジット |
| 音声 (Open JTalk / HTS Voice Mei) | 修正 BSD / CC BY 3.0 | 概要欄にクレジット |
| 音声 (VOICEVOX) | キャラクターごとの規約 | 「VOICEVOX:キャラ名」を自動記載。使用前に規約を確認 |
| BGM・効果音 | プログラムで合成したオリジナル | 概要欄に記載 |
| 文様・図解 | プログラムで描画 | — |

## AI・合成コンテンツの開示
- AI 画像を使った動画は API で `containsSyntheticMedia=true`、概要欄に制作方法を明記
- 実在の人物の顔や声の合成はしない。他人の声を複製しない

## 投稿・運営
- 公開は承認制 (自動公開はオーナーの明示的な承認後に、条件を決めて導入)
- 再生数・高評価・登録者・コメントの不正な増加は一切しない (相互登録・購入・自作自演)
- 同じ型の表面だけを変えた動画を量産しない。動画ごとに独自の企画・構成・裏取り・映像
- 動画の一括削除など実績を失う操作は、オーナーの承認なしに行わない

## 秘密情報
- API キー・クライアントシークレット・リフレッシュトークンは `.env` (git 管理外)・環境変数・`~/.config/ytops/token.json` (権限 600) のみ
- ダッシュボードの操作トークンは state/dashboard_token (権限 600)。ダッシュボードはインターネットに直接公開しない
