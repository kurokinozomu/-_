## 1. YouTube パートナープログラム (YPP) の条件

### 現在の条件 [公式] https://www.youtube.com/creators/earn/youtube-partner-program/ (2026-11-26 取得)
| 段階 | 条件 | 使える機能 |
|---|---|---|
| 広告収益 (目標) | 登録者 **1,000 人** + 「長尺の有効な公開視聴時間 **4,000 時間** (直近 365 日)」または「有効なショート視聴 **1,000 万回** (直近 90 日)」 | 広告収益・YouTube Premium の収益 |
| ファンからの支援など | 登録者 500 人 + 直近 90 日に公開動画 3 本 + 「3,000 時間 (365 日)」または「ショート 300 万回 (90 日)」 | メンバーシップ・Super Thanks など (広告収益は含まない) |

- 同ページの記載: **ショートフィードでの視聴時間は 4,000 時間に含まれない**。非公開・限定公開・削除済みの動画も含まれない
- 共通: 2 段階認証、コミュニティガイドラインの違反警告がないこと、AdSense の紐付け、YPP 提供地域に居住
- 条件を満たしても審査があり、承認は保証されない (チャンネル全体の審査。目安 1 か月程度 [二次])

### ★ 2027-02-01 からの変更 [二次: 多数の報道。YouTube コミュニティの公式スレッドの引用あり]
- 新規申請者の広告収益の条件が **2 倍**: 登録者 1,000 人 + **8,000 時間** または **2,000 万回**
- すでに YPP に参加しているチャンネルは対象外
- ファン支援の段階 (500 人) は変更なし
- ショートの広告収益の配分を受けるには、毎月「直近 90 日 1,000 万回」の維持が必要になるとの報道あり (対象範囲は報道により食い違い)
- **2/1 より前に申請し審査中だった場合の扱いは、公式の記載を確認できていない** (旧基準で審査されるとする記事と、そうでない記事がある)
- 参照: [ITmedia](https://www.itmedia.co.jp/news/article/2608/11/2000000495/), [Forbes](https://www.forbes.com/sites/gabrielalinzainescu/2026/08/11/youtube-doubles-the-monetization-bar-for-new-creators/), [YouTube コミュニティ](https://support.google.com/youtube/thread/451804019/updates-to-the-youtube-partner-program-new-earning-opportunities-changes-to-eligibility?hl=en), [trendmap.jp](https://trendmap.jp/blog/youtube-ypp-2027-monetization-requirements)

**プロジェクトへの影響**: 運営 Day 67 (2027-02-01) で条件が 2 倍になる。90 日目 (2027-02-23) の時点で求められるのは「8,000 時間 または 2,000 万回」。
→ MASTER_PLAN.md の「2 段構えの目標」を参照。

## 2. 独自性のないコンテンツ (inauthentic content) [二次 + 公式・検索経由]
- 2025-07-15 に「繰り返しの多いコンテンツ」が「独自性のないコンテンツ (inauthentic content)」に名称変更・明確化
- 対象: 大量生産・テンプレートの使い回し・ほぼ同じ内容の繰り返し・ナレーションの乏しいスライドショー
- **AI を使ったこと自体は対象ではない**。違反はチャンネル単位で収益化の対象外になりうる
- 本プロジェクトの対策: 動画ごとに独自の企画・構成・裏取り・出典。過去の台本との類似度を自動測定し 60% 以上は公開禁止 (ytops/qa.py)。テンプレ型「〇〇5選」の量産はしない

## 3. 再利用されたコンテンツ (reused content)
- 他人の動画・映画・テレビ・SNS の転載、ほぼ手を加えない編集は対象。本プロジェクトの素材はすべて自作 (AI 生成画像・プログラム生成の図・合成 BGM・合成音声) のため該当しない設計
- 公式本文 (support.google.com/youtube/answer/1311392) は直接取得できなかった → **要再確認** (オーナーまたはネット接続のある環境で)

## 4. 改変・合成コンテンツの開示 [公式・検索経由] https://support.google.com/youtube/answer/14328491
- 「本物と見間違える可能性がある」改変・合成コンテンツは、アップロード時に開示が必要。明らかに非現実的なもの・軽微な編集は不要
- 開示ラベル自体は、おすすめ表示や収益化の可否に影響しない
- 開示しない状態が続くとラベルの強制付与・削除・YPP 停止の可能性
- 本プロジェクトの運用: AI 画像を使った動画はすべて API の `containsSyntheticMedia=true` で開示 + 概要欄に制作方法を明記 (保守的)

## 5. YouTube API
- 未監査の API プロジェクトからアップロードした動画は「非公開」に固定される、という記載が日本語版ドキュメントに残っている。英語版では改訂されている可能性 [公式・検索経由・記載が食い違い]
  → 本プロジェクトは「非公開でアップロード → オーナー承認 → 予約公開」。もし API からの公開設定ができない場合は、Studio アプリで公開ボタンを押す運用に切り替える (1 本 10 秒)。恒久対応は API の監査申請 (無料・審査に数週間)
- 利用枠: 1 日 10,000 ユニット (既定)。アップロード 1 回のコストは改訂で記載が揺れている (1,600 または別バケット) → 保守的に 1,600 で計算し、1 日 4 本まで
- OAuth 同意画面が「テスト」状態のままだと、更新トークンが 7 日で失効する → 「本番」に切り替える (OWNER_TASKS.md)
