## 技術選定

| 候補 | 判定 | 理由 |
|---|---|---|
| Python + FFmpeg (既存 aivideo) | **採用** | 無料・安定・CPU だけで動く・実績あり (88 本制作済み) |
| Remotion | 不採用 | 商用利用は条件によりライセンス費用が必要になる場合があり、Node + Chromium のレンダリングは CPU 負荷が高い。現状の機能で足りる |
| ローカル実行 (オーナーの PC) | **推奨 (第一候補)** | VOICEVOX が使えて音声品質が上がる。認証情報を PC 内に置ける。PC が起動している時間だけ動く |
| クラウド実行 (Claude Code のスケジュール実行) | 第二候補 | PC 不要。ただし状態をリポジトリに保存する必要があり、リポジトリの非公開化が前提。音声は Open JTalk |
| GitHub Actions | 不採用 (現時点) | 台本生成に有料 API が必要になる、公開リポジトリだとログが見える |
