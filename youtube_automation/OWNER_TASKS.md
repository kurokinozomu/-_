# オーナーに必要な作業 (これ以外はすべてシステムと Claude が行います)

画面の名前は 2026-11 時点の一般的な表記です。表記が違う場合は近い名前の項目を選んでください。
合計の所要時間: 初回 約 60〜80 分 / 以降は毎日 約 5 分 (承認のみ)

## 【手順 0】方針の承認とリポジトリの非公開化 (5 分) ★最初に
**作業内容**: (1) MASTER_PLAN.md の「目標の再設定」とジャンル・チャンネル名を承認 (Claude への返信で OK)。(2) GitHub リポジトリ `kurokinozomu/-_` を非公開にする
**理由**: このリポジトリは現在 **公開** です。今後、再生数などの運営データや日報を保存すると誰でも見られます。非公開化はアカウントの重要な設定のため、Claude からは変更しません
**手順 (GitHub アプリまたはブラウザ)**: リポジトリ → Settings → General → 一番下の Danger Zone → Change repository visibility → Make private → リポジトリ名を入力して確定
**完了後に Claude が行うこと**: 運営データをリポジトリに保存する設定 (クラウド実行の準備) を有効化

## 【手順 1】Google アカウントと 2 段階認証 (10 分)
**理由**: 収益化の必須条件。本人確認は本人しかできません
1. チャンネル専用の Google アカウントを推奨 (既存のアカウントでも可)。https://accounts.google.com/signup
2. https://myaccount.google.com/security → 「2 段階認証プロセス」→ 有効にする (スマホの Google 認証システムまたは SMS)
3. 生年月日・居住国は **正しい情報** を入力してください (虚偽の設定は規約違反)

## 【手順 2】YouTube チャンネルの作成と初期設定 (20 分)
1. スマホの YouTube アプリ → 右下のアイコン → 「チャンネルを作成」(PC: youtube.com → 右上アイコン → チャンネルを作成)
2. 名前: **むかし暮らし研究所** (手順 0 で別案を選んだ場合はその名前)。ハンドル: `@mukashi-kurashi-lab` (使用済みなら候補 2・3)
   - 事前に YouTube で同名のチャンネルがないか検索してください
3. 電話番号の確認 (カスタムサムネイル・長い動画・予約投稿に必要): https://www.youtube.com/verify
4. YouTube Studio (https://studio.youtube.com) → 設定:
   - **チャンネル → 基本情報**: 居住国 = 日本 (実際の居住国)、キーワード: 江戸,暮らし,歴史,生活史,睡眠用,聞き流し
   - **チャンネル → 詳細設定**: 「子ども向けではない」を選択
   - **チャンネル → 機能の利用資格**: 「中級者向け機能」「上級者向け機能」を申請 (上級者は本人確認書類か動画による確認が必要な場合あり)
   - **アップロード動画のデフォルト設定**: 公開設定 = 非公開 / カテゴリ = 教育 / 動画の言語 = 日本語 / コメント = 「不適切な可能性があるコメントを保留」
   - **コミュニティ**: 自動フィルタはデフォルトのまま
5. **カスタマイズ → ブランディング**: `branding/out/icon_800.png` (プロフィール)、`banner_2560x1440.png` (バナー)、`watermark_150.png` (透かし・「動画の最後」または「全体」)
6. **カスタマイズ → 基本情報**: 説明に strategy/channel_design.md の「概要欄 (チャンネル)」を貼り付け
**完了後に Claude が行うこと**: 初回の動画を非公開でアップロードし、スマホでの見え方を確認してもらう

## 【手順 3】Google Cloud で API を有効化 (20 分・無料・課金設定は不要)
**理由**: 自動アップロード・予約投稿・分析は公式 API でしか行いません (ブラウザの自動操作は規約違反)
1. https://console.cloud.google.com → 上部のプロジェクト選択 → 「新しいプロジェクト」→ 名前 `mukashi-kurashi-ops` → 作成
2. 「API とサービス」→「ライブラリ」→ **YouTube Data API v3** を検索して「有効にする」。同様に **YouTube Analytics API** も有効化
3. 「API とサービス」→「OAuth 同意画面」(または「Google Auth Platform」):
   - ユーザーの種類: **外部** / アプリ名: `mukashi-kurashi-ops` / サポートメール・デベロッパーの連絡先: ご自身のメール
   - 対象 (テストユーザー): チャンネルの Google アカウントを追加
   - **公開ステータスを「本番環境」に切り替え** (「テスト」のままだと 7 日ごとに認証が切れます。未確認アプリの警告が出ますが、自分だけが使う分には問題ありません)
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類 **デスクトップ アプリ** → 作成 → クライアント ID とシークレットを控える
5. 「認証情報を作成」→「API キー」→ 作成後「キーを制限」→ API の制限 = YouTube Data API v3 (競合分析用)
6. 控えた 3 つを **PC のリポジトリ直下の `.env`** に書く (チャットには貼らないでください):
   ```
   YT_CLIENT_ID=xxxxx.apps.googleusercontent.com
   YT_CLIENT_SECRET=xxxxx
   YT_API_KEY=xxxxx
   ```
   `.env` は git の管理外です。クラウドで動かす場合は scheduler/README.md の手順で環境変数に入力します

## 【手順 4】OAuth 認証 (5 分)
1. PC で: `python -m ytops auth` → ブラウザが開く → チャンネルのアカウントを選択 →「このアプリは確認されていません」→「詳細」→「(安全ではないページ) に移動」→ 権限をすべて許可
   - スマホしかない場合: `python -m ytops auth --manual` を Claude に実行させ、表示された URL をスマホで開いて許可 → 「接続できません」画面のアドレスをコピーしてターミナルに貼る
2. トークンは `~/.config/ytops/token.json` (権限 600) に保存されます
**完了後に Claude が行うこと**: 非公開アップロード・予約投稿・分析の動作確認、競合 30 チャンネルの数値取得

## 【手順 5】毎日の承認 (毎日 5 分)
- ダッシュボード (`python -m ytops dashboard --serve`) または Claude アプリで「承認待ちを見せて」→ 動画を確認 →「承認」
- YouTube Studio アプリの「非公開」動画からも内容を確認できます
- 人間の確認が必要と判定された動画 (医療・法律・未確認の重要な主張など) は、審査結果 (qa.md) を読んで判断

## 【後日】収益化の申請 (条件達成時・30 分)
1. YouTube Studio → 収益化 → 条件を確認 →「申請」→ 規約に同意
2. AdSense アカウントの作成・紐付け (住所・支払い情報はご自身で入力)
3. 申請から審査結果まで約 1 か月 (目安)。不承認の場合は 30 日後に再申請可能 (Claude が改善計画を作成)
