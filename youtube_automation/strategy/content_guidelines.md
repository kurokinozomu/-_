# 台本・制作のガイドライン (実装との対応つき)

## 形式ごとの基本構成 (毎回固定せず、テーマに合わせて変える)
| 形式 | 長さ | 構成 | 実装 |
|---|---|---|---|
| ショート | 35〜50 秒 (検証対象) | 冒頭 1 文で意外な事実 or 問い → 理由を 1 つ → 具体例 → 余韻 or「詳しくは関連動画で」 | aivideo `--shorts --related`、語り口は ops.KIND_ENV["short"] |
| 長尺 (解説) | 8〜12 分 (維持率で調整) | 引きの強い導入 → 見るメリット → 背景 → 本題 → 具体例 (値段・時刻・史料) → 独自の分析 (現代との比較) → 結論 → 関連動画 | aivideo の 2 段階生成 (章立て → 章ごとのシーン)、ops.KIND_ENV["long"] |
| 睡眠用 | 30〜60 分 | 穏やかな導入 → 季節・時刻順に情景をたどる → 刺激の少ない締め。問いかけの連発・大きな展開・効果音を避ける | ops.KIND_ENV["sleep"] (ゆっくりした声・話速 0.95・AI 画像は 3 シーンに 1 枚) |

## 冒頭パターン (A/B 検証の候補・1 週間に 1 変数ずつ)
1. 意外な事実:「江戸の銭湯の湯船は、薄暗くて隣の顔も見えなかったんです」
2. 二人称の没入:「明け六つの鐘。あなたは長屋の布団で目を覚まします」
3. 値段の問い:「江戸のかけそば一杯、いまのお金でいくらだと思いますか」
4. 現代との対比:「私たちが当たり前に使う〇〇、江戸にはありませんでした」

## 禁止事項 (自動審査で検出するもの / 人が見るもの)
| 禁止 | 検出 |
|---|---|
| 他チャンネルの台本のコピー・Web 記事の読み上げ | 台本 AI への指示 + 事実確認時の LLM 審査 (人の確認も) |
| 根拠のない情報・存在しない出典 | LLM + WebSearch の裏取り。URL は検索で見たものだけ (qa.llm_review) |
| 誤解を招く表現・過度な煽り | タイトルの煽り語の減点 (qa.HYPE_WORDS)、LLM の台本審査 |
| 内容の薄い尺稼ぎ・同じ内容の繰り返し | LLM の台本審査 (script 点) |
| 不自然な登録誘導 | qa.BANNED_PATTERNS |
| 過去動画との重複 | 4-gram の類似度 (qa.check_originality) |

## 台本に付ける情報
台本シート (scripts/<ID>.md・ytops/scriptsheet.py): 時刻 / ナレーション (読み上げ時間の目安) / 映像指示 (カメラ・転換・画像プロンプト) / 字幕指示 (見出し・強調語) / 効果音 / 事実確認の結果 / 出典

## 音声の検査 (自動)
ラウドネス -14 LUFS 前後 (許容 -17.5〜-11.5)・トゥルーピーク -0.5 dBFS 以下 (クリッピング防止)・2.5 秒以上の途中の無音 (睡眠用は除外)。BGM はナレーション中に自動で下げる (aivideo/audio.py)
誤読対策: 読み替え辞書 `data/readings.json` (音声だけを置換し、字幕は元の表記)。2026-11-26 に江戸の用語 24 語を Open JTalk で検査し、誤読した 柘榴口・入込湯・一刻・二八そば などを登録済み。読みはカタカナで書く (ひらがなの「は」が助詞「ワ」と読まれるため)

## 映像
- 素材はすべて自作。実在の人物・ロゴ・作品・浮世絵の転載はしない
- 単純なスライドショーにしない: シーンごとのカメラワーク・場面転換・見出しテロップ・図解 (値段・時刻) を使う
- 時代考証: 台本 AI に時代に合わない物 (時計・電灯など) を描かないよう指示済み。最終確認は人の目で
