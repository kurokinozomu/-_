## テスト結果 (2026-11-26)
### 長尺「江戸の銭湯はどんな場所だった？」(8 分指定 → 7 分 26 秒)
| 版 | 内容 | 点数 | 判定 |
|---|---|---|---|
| 初版 | 既定の設定 (AI 画像と絵文字イラストが交互・黄色の派手なテロップ) | 80 | 人間の確認 (映像 4/15) |
| 修正版 r1 | 審査の指摘で台本を自動修正 + 落ち着いたブランド表現 + 時代指定 + 誤読辞書 + 丸数字の修正 | 80 | 人間の確認 (映像 4/15) |
- 満点: 音声 10・字幕 5・規約 10・独自性 20 (過去動画との類似 12%)。正確性 15/20、台本 11/15
- 裏取り: 実在の URL 5 件 (上越市の資料 PDF・nippon.com・国文学研究資料館のリポジトリ等) を概要欄に自動追記
- **公開できない理由 (映像)**: 無料の画像 AI が、プロンプトで「行灯の明かり」と指定しても現代の電気スタンドを描く、空に電線のような線、写実的な人物など。否定形の指示を肯定形に変えた試作で町並みは改善したが、人物の場面は改善しきれていない
- 人の確認が必要な史実: 寛政 3 年の混浴禁止令・天保の再禁止の典拠、『守貞謾稿』の二階座敷の記述、男女日替わり営業の例
- 制作時間: 初版 約 40 分 / 修正版 約 65 分 (画像生成が律速。無料枠は約 1 枚/分)
- サムネイル 3 案: 見出しのはみ出し・途中切れを検出するよう改良後、C (問いかけ型) 100 点 / B 82.5 / A 78.5。タイトルとサムネの文言の重複を検出し別案を提示

### 映像の改善案 (要判断)
1. **パブリックドメインの浮世絵・古写真** (美術館のオープンアクセス、CC0 等) を図版として使う: 本物の時代資料で考証の問題が消え、独自性も上がる。この環境からは美術館の API に接続できない (オーナーの PC からは可能)。費用 0 円
2. 画像 AI の有料プラン (Pollinations のキー等): 高品質なモデル・ロゴなし。**有料のため承認が必要**
3. 現状のまま、映像審査で減点された場面だけ人が差し替える
