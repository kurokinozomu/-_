# 忘却都市 — 設計メモ

## 1. コンセプト
「生きるために、人生を忘れていく。」
記憶を売ると、プレイヤーが見る世界そのもの（文字・顔・会話・地図）が変わる。
売却は数値ではなく「体験の喪失」として表現し、正解/不正解を作らない。

## 2. 物語設定（スタッフ向け・ネタバレ）

| 人物 | 役割 |
|---|---|
| 水瀬 湊（主人公） | 借金10万円。実は**一年前にも同じことをしている**（周回の示唆）。|
| 水瀬 春子（母） | 電話だけで登場。売却後は声だけの「知らない女」になる。「また、なのね」＝前回も売られた。|
| 佐伯（隣人の老婆） | 母を知る人。売却後は母の名前が聞き取れなくなる。町の住人が「知らない顔」になっていくのを見てきた。|
| 源（屋台の店主） | 買取店の存在を教える。売った者を何人も見ている。|
| フードの女（凪） | 「大切な人」。主人公はすでに彼女の顔と名前を売っている。残っているのは「雨の橋の下の約束」の記憶だけ。|
| 烏間（買取店） | 「初めて……ではありませんね」。メモリアの店主。|

**秘密**: 記憶買取店メモリアと金融会社ミナカミ・ファイナンスは同じ組織。返せない借金を作らせ、記憶を「差し押さえる」。
主人公は一年前にも借金を背負わされ、記憶を売り、売ったことを忘れて同じ町で暮らしている。
引き出しの鍵（Phase 3）の中に、過去の自分のメッセージ「もしこの文章を読んでいるなら、あの人の記憶だけは絶対に売るな。」がある。

### 物語の流れ（Phase 3 実装済み）
1. 1日目: 督促状 → 買取店 → 母の電話（売れば違和感の電話）
2. 2日目の朝: 橋の夢を見る → 傾いた写真立ての裏に鍵 → 机の引き出しに **過去の自分の手紙**「あの人の記憶だけは絶対に売るな」と **去年の契約書**（証拠1）
   - 文字の記憶を売っていても、手紙の挿絵（橋と傘のふたり）で場所が分かる
3. 湾岸通り東端の階段 → **橋の下**で凪と再会。名前・去年の真相・「夜の店に台帳がある」と聞き、約束するかを選ぶ
4. 夜（ベッドで夜まで休める）のメモリアは無人 → **顧客台帳**（証拠2）「霧野町内 214件・次回査定一年後」
5. 店先のポスター「提携：ミナカミ」（証拠3）→ 烏間に証拠を突きつけられる

### エンディング（6種類・Phase 3 実装済み）
| ID | 名前 | 条件 | 物語上の理由 |
|---|---|---|---|
| A protected | 雨上がりの橋 | 凪と約束し、大切な人の記憶を売らずに完済 | 売らずに守った「約束」だけが、顔も名前も失った二人を再びつなぐ |
| B forgotten | 忘却の朝 | 大切な人の記憶を売って完済 | 痛みごと手放したから生きていける。手紙の意味ももう分からない |
| C secret | メモリア閉店 | 3つの証拠で烏間と対決し、取引を断る | 仕組みを暴けば借金は無効になる。記憶は戻らないが町は名前を呼び直す |
| D paid | 返済完了 | 約束せずに完済 | 日常には戻れたが、待っている誰かに気づかないまま |
| E seized | 差押え | 期限までに返せない | 記憶で「差押え」られ、知らない部屋で目覚める（一年後の自分＝周回の始まり） |
| F loop | はじめてのお客様 | 対決で「気づいた記憶」まで売る | 秘密ごと売れば、一年後にまた同じ扉が開く |

見たエンディングは `user://oblivion_records.json` に記録し、タイトルに「エンディング n/6 [A・C…]」と表示する（セーブとは別、エンディング後も残る）。

Phase 1 で既に仕込んだ伏線: 烏間の「初めてでは」、母の「また、なのね／去年の今ごろ」、ポスターの「提携：ミナカミ」、棚の瓶「湊／母」、凪の「最初にあのお店に行った日から」、鍵のかかった引き出し。

## 3. システム設計

### 3.1 データ駆動
- 数値・記憶・会話・マップ・紙・目標・エンディングはすべて `data/*.json`。
- 会話スクリプトは「ステップの配列」。`say / choice / if / set / unset / rel / money / action / run / wait`。
- 条件式はスペース区切りの AND: `sold:mother !flag:x day>=2 rel:saeki>=1 money>=150`。
- 本文中の `{token}` は `config.json` の `tokens` で置換。`memory` 指定の記憶が売却済みなら `[g]…[/g]` になり、
  会話では**ちらつく記号列**、HUD・看板では伏せ字（？）として表示される。→「言葉が理解できなくなる」体験。

### 3.2 記憶の影響（実装状況）
| 記憶 | 価格 | 影響 | 状態 |
|---|---|---|---|
| 母親 | 20,000 | 母の名前・呼称が読めない／電話の相手が分からない／写真の顔が砂嵐／隣人の会話が変化／見覚えのないメモ・タッパー・マグカップ | **Phase 1 実装済み** |
| 街 | 12,000 | 施設名・地名が「？」になりネオンが壊れて点滅／道案内の看板が消える／近道の路地が使えなくなる／店主が「ご自宅は西の端ですよ」 | **Phase 2 実装済み** |
| 仕事 | 15,000 | 仕分けの補助（正しい棚が光る）が消え、棚割りが毎回変わる／主任に新人扱いされ日給 1,500→800円／代わりに「荷運び」（固定3,500円）を発見 | **Phase 2 実装済み** |
| 文字 | 30,000 | 紙・看板・目標表示・ATM・仕分けの区画名など「書かれた文字」の漢字・かなの約6割が崩れる。数字・図形アイコンは読める（仕分けは図形で続けられるが、図形が擦れた荷物は勘になる） | **Phase 2 実装済み** |
| 大切な人 | 50,000 | 二重の確認／写真の人物が背景ごと抜け落ちる／フードの女が「もう待たなくていいよね」と去り、以後現れない／烏間「前回と同じように」 | **Phase 2 実装済み**（核心イベントの変化は Phase 3）|

`say` / 選択肢に `"written": true` を付けると「書かれた文字」扱いになる（ATM画面、スマホ通知など）。会話（話し言葉）は崩れない。

### 3.2b 生活・お金・時間
- 1日 = 朝 / 昼 / 夕方 / 夜。仕事をすると 2 つ進む。仕事の受付は朝・昼のみ。夜は画面が暗く、隣人は家に帰っている。
- 毎朝、生活費 2,000円。払えない分は ×1.1 で借金に「自動融資」される（頼んでいないのに — ミナカミの手口）。
- ATM（湾岸通り）で 1万 / 3万 / 全額を返済。完済すると仮エンディング（本編のエンディングは Phase 3）。
- 仕分け: 荷物は 1.6秒ごとに1個、40秒で最大25個 → 1日最大 約9,000円。7日働いても約6.3万円で、
  借金10万円には記憶を売る必要がある（母+街+仕事 ＝ 4.7万、文字 3万、大切な人 5万 …どれを手放すかがプレイヤーの選択）。

### 3.3 描画・性能
- 基準解像度 640x360、`canvas_items` 拡大 + `expand`（どのアスペクト比でも黒帯なし）、ワールドはカメラ2倍。
- タイルは1ノードで一括描画し、変化時のみ再描画。アニメするものだけ毎フレーム再描画。
- 衝突判定はタイルグリッド + 矩形（物理エンジン不使用）。低FPSでも壁際まで寄れるよう細分化移動。
- 画面ノイズは画面テクスチャを読まないシェーダー（モバイルで軽い）。売却数で強くなる。
- マップ切替は 0.2 秒のフェードのみ（ロードなし）。

### 3.4 Web・モバイル対応
- GL Compatibility レンダラ、スレッド無し書き出し（SharedArrayBuffer/COOP/COEP 不要）。
- 日本語はブラウザのフォントに頼れないため DotGothic16 を同梱。テストで全文字の収録を検査。
- タッチ: 左半分のどこでも出る仮想スティック + 右下の調べるボタン（マルチタッチ対応）。会話はタップで進む。
- セーフエリア: ネイティブは `DisplayServer.get_display_safe_area()`、Web は CSS `env(safe-area-inset-*)` を参照。
- 縦向きでは HTML 側で「横画面にしてください」を表示。
- セーブは `user://`（Web では IndexedDB）。失敗時・永続化できない環境（プライベートモード等）ではエラー表示。
- `?autotest` 付きURLでのみ `window.__ob` に状態を公開（ブラウザ自動テスト用）。

### 3.5 音
- `tools/gen_audio.py` が numpy で合成し、ffmpeg で OGG にする（全部で約0.6MB）。2周分レンダリングして後半を使うので、残響込みで継ぎ目なくループする。
- BGM: title（橋の下でも使用）/ town / home / shop / work / ending。雨音は屋外でそのまま、屋内ではローパスでくぐもらせる。
- `Sound` オートロード: BGMのクロスフェード、効果音のプール、音量4段階（メニューで切替・`user://oblivion_settings.json` に保存）。
