# 忘却都市 — 設計メモ

## 1. コンセプト
「生きるために、人生を忘れていく。」
記憶を売ると、プレイヤーが見る世界そのもの（文字・顔・会話・地図）が変わる。
売却は数値ではなく「体験の喪失」として表現し、正解/不正解を作らない。

## 2. 物語設定（スタッフ向け・ネタバレ）

| 人物 | 役割 |
|---|---|
| 水瀬 湊（主人公） | 借金10万円。実は**一年前にも同じことをしている**（周回の示唆）。|
| 水瀬 春子（母） | 電話だけで登場。売却後は声だけの「知らない女」になる。「また、なのね」＝前回も売られた。|
| 佐伯（隣人の老婆） | 母を知る人。売却後は母の名前が聞き取れなくなる。町の住人が「知らない顔」になっていくのを見てきた。|
| 源（屋台の店主） | 買取店の存在を教える。売った者を何人も見ている。|
| フードの女（凪） | 「大切な人」。主人公はすでに彼女の顔と名前を売っている。残っているのは「雨の橋の下の約束」の記憶だけ。|
| 烏間（買取店） | 「初めて……ではありませんね」。メモリアの店主。|

**秘密**: 記憶買取店メモリアと金融会社ミナカミ・ファイナンスは同じ組織。返せない借金を作らせ、記憶を「差し押さえる」。
主人公は一年前にも借金を背負わされ、記憶を売り、売ったことを忘れて同じ町で暮らしている。
引き出しの鍵（Phase 3）の中に、過去の自分のメッセージ「もしこの文章を読んでいるなら、あの人の記憶だけは絶対に売るな。」がある。

### エンディング（Phase 3 で実装）
1. **記憶を守り抜く**: 大切な人の記憶を売らずに返済 → 橋の下で凪と再会。何かは失っても「約束」は残る。
2. **大切な記憶を失って生き延びる**: 大切な人の記憶を売って完済 → 生活は続くが、凪は永遠に他人。メモの意味も分からない。
3. **記憶売買の秘密を発見する**: ポスターの提携表記・棚の自分のラベル・去年の契約書などの手がかりを集め、メモリアとミナカミの関係を暴いて周回を断つ。

Phase 1 で既に仕込んだ伏線: 烏間の「初めてでは」、母の「また、なのね／去年の今ごろ」、ポスターの「提携：ミナカミ」、棚の瓶「湊／母」、凪の「最初にあのお店に行った日から」、鍵のかかった引き出し。

## 3. システム設計

### 3.1 データ駆動
- 数値・記憶・会話・マップ・紙・目標・エンディングはすべて `data/*.json`。
- 会話スクリプトは「ステップの配列」。`say / choice / if / set / unset / rel / money / action / run / wait`。
- 条件式はスペース区切りの AND: `sold:mother !flag:x day>=2 rel:saeki>=1 money>=150`。
- 本文中の `{token}` は `config.json` の `tokens` で置換。`memory` 指定の記憶が売却済みなら `[g]…[/g]` になり、
  会話では**ちらつく記号列**、HUD・看板では伏せ字（？）として表示される。→「言葉が理解できなくなる」体験。

### 3.2 記憶の影響（実装状況）
| 記憶 | 価格 | 影響 | 状態 |
|---|---|---|---|
| 母親 | 20,000 | 母の名前・呼称が読めない／電話の相手が分からない／写真の顔が砂嵐／隣人の会話が変化／見覚えのないメモ・タッパー・マグカップ | **Phase 1 実装済み** |
| 街 | 12,000 | 看板（`{shop_name}` 等）が「？？？」になりネオンが壊れる／案内板が読めない | トークン・看板の仕組みは実装済み。売却は Phase 2 で解禁 |
| 仕事 | 15,000 | ミニゲームの操作補助が消え難易度上昇／別の働き方を発見 | Phase 2 |
| 文字 | 30,000 | 紙・看板・選択肢の文字が崩れる（アイコン情報は読める） | Phase 2（`[g]` の仕組みを全文に適用する予定）|
| 大切な人 | 50,000 | 凪との関係を忘れる／核心イベント変化 | Phase 2〜3 |

### 3.3 描画・性能
- 基準解像度 640x360、`canvas_items` 拡大 + `expand`（どのアスペクト比でも黒帯なし）、ワールドはカメラ2倍。
- タイルは1ノードで一括描画し、変化時のみ再描画。アニメするものだけ毎フレーム再描画。
- 衝突判定はタイルグリッド + 矩形（物理エンジン不使用）。低FPSでも壁際まで寄れるよう細分化移動。
- 画面ノイズは画面テクスチャを読まないシェーダー（モバイルで軽い）。売却数で強くなる。
- マップ切替は 0.2 秒のフェードのみ（ロードなし）。

### 3.4 Web・モバイル対応
- GL Compatibility レンダラ、スレッド無し書き出し（SharedArrayBuffer/COOP/COEP 不要）。
- 日本語はブラウザのフォントに頼れないため DotGothic16 を同梱。テストで全文字の収録を検査。
- タッチ: 左半分のどこでも出る仮想スティック + 右下の調べるボタン（マルチタッチ対応）。会話はタップで進む。
- セーフエリア: ネイティブは `DisplayServer.get_display_safe_area()`、Web は CSS `env(safe-area-inset-*)` を参照。
- 縦向きでは HTML 側で「横画面にしてください」を表示。
- セーブは `user://`（Web では IndexedDB）。失敗時・永続化できない環境（プライベートモード等）ではエラー表示。
- `?autotest` 付きURLでのみ `window.__ob` に状態を公開（ブラウザ自動テスト用）。

## 4. ロードマップ
- **Phase 1（完了）**: タイトル / 移動 / 自宅・街・買取店 / NPC会話 / 母親の記憶の売却と世界の変化 / PC・スマホ操作 / セーブ
- **Phase 2**: 倉庫仕分けミニゲーム（タッチ対応・制限時間・仕事の記憶で難易度変化）、職場マップ、残り4種の記憶の解禁と影響、生活費・借金返済窓口、時間帯
- **Phase 3**: ストーリーイベント（引き出しの鍵・橋の下・去年の契約書）、エンディング3種、BGM/効果音（自作・無料素材）、演出強化、不具合修正
- **Phase 4**: Web公開（GitHub Pages 等）、実機確認（iPhone Safari / Android Chrome）、読み込みサイズ最適化（フォントのサブセット化等）
