# 転生したらレベル1の村人だった — シーズン1 (全30話)

縦型ショートドラマ (1話 60〜90秒)。各話は単独でも楽しめ、全体で主人公が「最弱の村人」から「世界を救う英雄」へ成り上がる。

## 隠された能力 (シリーズの軸)
**【模倣 (コピー)】** 一度見たスキルを、一度だけ写し取って使える。レベルが上がるほど「写せる回数」「保持できる数」が増え、最終的には複数のスキルを組み合わせた【融合】へ進化する。
制約: 写したスキルは本家より弱い / 一度使うと消える (序盤) / 「理解」できない力は写せない — この制約が毎話の葛藤とアイデアを生む。

## 主要キャラクター
| 名前 | 立場 | 役割 |
|---|---|---|
| 相馬 湊 (ミナト) | 主人公・25歳・元会社員 | 職業「村人」Lv1。観察眼と機転で戦う |
| リナ | 辺境の村の娘・18歳 | 最初の味方。薬草師見習い。実は古代エルフの血筋 |
| ガルド | 王国騎士・炎魔法の使い手 | 序盤のライバル。傲慢だが、後に共闘する |
| 神官オルド | 村の鑑定神官 | 職業鑑定をする老人。湊の能力の正体を知る鍵 |
| 影の勇者 カイン | 謎の転生者 | 終盤の敵。湊と同じ日に死んだ「もう一人の転生者」 |

## 3幕構成
- **第1幕 (1〜10話) 村編**: 見下される村人 → 模倣の発見 → 村を守るヒーローに
- **第2幕 (11〜20話) 王都編**: 冒険者ギルドで最底辺から成り上がる → 能力の秘密と「もう一人の転生者」の影
- **第3幕 (21〜30話) 決戦編**: 魔王軍と影の勇者 → 模倣の進化【融合】→ 最弱の村人が世界を救う
