# 転生したらレベル1の村人だった — 制作メモ

| ファイル | 内容 |
|---|---|
| `season1.md` | 全30話の構成 (各話のフック・展開・引き) |
| `characters.md` | キャラクター設定、声、字幕の色、見た目をそろえるための英語の固定記述 |
| `build_ep01.py` | 第1話のカット表 (セリフ・話し手・映像プロンプト・カメラ・転換・効果音) を作る |
| `ep01_plan.json` | 上で作ったカット表。`python -m aivideo --plan` でそのまま動画になる |

```bash
python drama/tensei_murabito/build_ep01.py
python -m aivideo --plan drama/tensei_murabito/ep01_plan.json --shorts --out output/drama
```

## 有料にすると良くなるところ (未実施・実行前に必ず確認)

Pollinations のキー (Pollen、1 Pollen = 1 米ドル、前払い) があれば、同じ仕組みで次ができる。料金は Pollinations のモデル一覧に載っていた値で、購入前に最新の料金を確認すること。

1. **参照画像で顔をそろえる**: 主人公の正面・横顔の参照画像を 1 回作り、各カットはそれを入力にして生成する (画像編集・参照対応のモデル)。1カット数円程度
2. **静止画を動画にする**: 各カットの画像を始点に 3〜8 秒の動画を生成する

| 動画モデル (例) | 画質 | 1話 (約80秒) | 30話 |
|---|---|---|---|
| p-video / seedance-1-pro-fast | 720p〜1080p | 約1.6ドル (約240円) | 約48ドル (約7,200円) |
| grok-imagine-video | 720p | 約4ドル (約600円) | 約120ドル |
| kling-v3.0-std / veo-3.1-fast | 720p〜1080p 高品質 | 約6.5ドル (約1,000円) | 約200ドル (約3万円) |

※ 1ドル150円で計算。作り直しが出ると、その分だけ増える。
